## ⚡ Fix #1: Android Location Permission (PALING PENTING!)

**⏱️ 2 Menit**

### Step 1: Buka Chrome Settings
```
Chrome Menu (hamburger ☰) → Settings
```

### Step 2: Apps & Notifications
```
Settings → Apps & notifications
Atau: Settings → Permissions
```

### Step 3: Kasir-Pro App
```
Cari "Kasir-Pro" di list
Tap → Permissions
```

### Step 4: Enable Location
```
Location: ⭕ (OFF) → 🟢 (ON)
```

✅ **SELESAI!** Ini fix 80% kasus!

---

## ⚡ Fix #2: Restart Chrome (2 Menit)

**After enabling location:**

```
1. Close Chrome completely (swipe dari recent apps)
2. Wait 10 seconds
3. Open Chrome lagi
4. Go to: kasir-pro-v2-rusmana.vercel.app
5. Settings → 🖨️ Printer Bluetooth
6. Click "Cari printer"
7. Select printer dari list ✅
```

---

## ⚡ Fix #3: Check Printer Pairing (1 Menit)

Jika masih tidak ditemukan:

```
Android Settings → Bluetooth
```

**Cek:**
- [ ] Printer sudah di list? (harus ada!)
- [ ] Status: "Paired" atau "Connected"?
- [ ] Jika belum paired: Tap printer → Pair

**Kalau printer tidak ada di list:**
1. Printer OFF/ON (restart)
2. Printer Bluetooth mode ON (cek manual printer)
3. Scan lagi

---

## ⚡ Fix #4: Clear Chrome Cache (1 Menit)

Jika masih stuck:

```
Chrome Menu → Settings → Privacy
Clear browsing data → Clear all
Close & reopen Chrome
```

## 📱 Hardware Checklist

Jika masih error, check hardware:

- [ ] Printer ON (LED hijau)
- [ ] Printer Bluetooth mode ON
- [ ] Battery printer > 50%
- [ ] Printer dalam 5 meter
- [ ] Paper tersedia

## 🔄 Full Reset (Last Resort)

Jika semua gagal:

```
1. Power off printer (30 seconds)
2. Power on printer
3. Unpair printer dari Bluetooth settings
4. Pair ulang
5. Restart Chrome
6. Coba scan ulang
```
